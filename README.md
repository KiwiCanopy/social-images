# KiwiCanopy social images

The images that went out with KiwiCanopy's posts on Threads and
LinkedIn, one folder per product, named by the date they were posted.

Nothing is prepared here. Images for upcoming posts live in a private
repository and are copied here by the posting job at the moment they
are posted, because Buffer fetches a post's image from a public
address.

KiwiDesk, KiwiCV and KiwiCall are built by Maikel Hajiabadi:
[kiwicanopy.com](https://kiwicanopy.com).
